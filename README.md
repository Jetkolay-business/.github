# .github

Jetkolay-business organizasyonunun profil sayfası, logo dosyaları ve tüm repolar için ortak issue / PR şablonları.

| Yol | İçerik |
| :--- | :--- |
| `profile/README.md` | Organizasyon sayfasında herkese görünen profil |
| `assets/` | Logo (`logo.png` 512×512 avatar, `logo.svg` kaynak) |
| `ISSUE_TEMPLATE/` · `PULL_REQUEST_TEMPLATE.md` | Kendi şablonu olmayan repolarda varsayılan şablonlar |

Üyelere özel profil ve repo haritası `.github-private` reposundadır.
